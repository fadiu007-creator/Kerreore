# Kerreore

Modern peer-to-peer marketplace for renting cars by the hour.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide icons

## Development

```bash
npm install
npm run dev
```

Then open the local Next.js development URL.

## Project docs

- [`docs/PLAN.md`](./docs/PLAN.md) — product and technical roadmap
- [`docs/WORKLOG.md`](./docs/WORKLOG.md) — completed work log

## Status

Phase 0 foundation is underway. The current branch contains the initial marketplace shell and homepage UI; backend, authentication, persistence, payments, and production booking logic are intentionally subsequent phases.
