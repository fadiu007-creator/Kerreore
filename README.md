# Kerreore

Modern peer-to-peer marketplace for renting cars by the hour.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide icons

## Development

```bash
npm install
npm run dev
```

Then open the local Next.js development URL.
